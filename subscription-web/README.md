# Сбер.Сканер Подписок — веб-сервис (MVP)

> **🌐 Открыть сканер онлайн (постоянная ссылка):** <https://ehity.github.io/5/>

Загружаете CSV или PDF-выписку — сервис находит
регулярные списания, считает потенциальную экономию, помечает подписки,
которые уже входят в другие (Кинопоиск в Яндекс Плюсе и т.п.), даёт
deep-links на отмену и генерирует готовое заявление на отказ от автопродления.

## Как открыть сканер

**Способ 1 — онлайн, ничего не устанавливая:** <https://ehity.github.io/5/>

Приложение работает целиком в браузере: CSV-выписка анализируется прямо на
странице (тот же алгоритм, портированный на JS). Есть встроенный генератор
тестовой выписки. Ограничение браузерного режима — PDF-выписки и сохранение
результата после перезагрузки страницы недоступны.

**Способ 2 — локально (полная версия: PDF + сохранение в SQLite):**

```bash
python -m pip install -r requirements.txt
```
и двойной клик по **`start_web.bat`** — поднимет сервер и откроет
**http://127.0.0.1:8000**.

**Способ 3 — публичная ссылка на полную версию за минуту (без аккаунтов):**
если сервер уже запущен, публикуем его через SSH-туннель Pinggy:

```bash
ssh -p 443 -R0:localhost:8000 free.pinggy.io
```
Команда выведет временный адрес вида `https://….free.pinggy.net` —
его можно открыть с любого устройства (бесплатная ссылка живёт 60 минут,
команду можно просто запустить заново).

**Способ 4 — постоянный серверный хостинг (кнопкой):**

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Ehity/5)

Клик → войти через GitHub → Render соберёт Docker-образ и даст постоянную
публичную ссылку (бесплатный тариф, сервис «засыпает» после 15 минут
бездействия и просыпается ~30 секунд).

## Стек

- **Backend**: FastAPI + Uvicorn + SQLite (анализ выписки, поиск подписок, генерация писем)
- **Frontend**: React 18 + Vite + Tailwind CSS + Recharts (дашборд, графики)

## Запуск с нуля

Нужен Python 3.11+. Node нужен только для пересборки UI — собранный
`frontend/dist` уже в репозитории.

```bash
git clone <repo-url> && cd subscription-web
python -m pip install -r requirements.txt

# Windows: двойной клик по start_web.bat — поднимет сервер и откроет браузер
# или вручную:
cd backend && python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Открыть **http://127.0.0.1:8000** — фронтенд раздаётся прямо FastAPI,
отдельный Node-сервер не нужен. Результат анализа сохраняется в
`backend/scanner.db` и переживает перезапуск сервера.

## Пересборка UI (опционально)

```bash
cd frontend && npm install && npm run build
```

## Как загрузить выписку

Поддерживаются **CSV** и **PDF** (текстовые выписки СберБанк Онлайн).

- `test_statement.csv` — CSV с «ловушками» (6 вариантов названий двух сервисов);
- `test_statement.pdf` — многостраничный PDF в формате выписки Сбера.

В интерфейсе есть кнопка «Сгенерировать тестовую выписку» — сервер сам
сделает выписку с подписками (в том числе с промо-ценой и сервисами,
входящими в экосистемные подписки).

## API

| Метод | Эндпоинт              | Описание                                        |
|-------|-----------------------|-------------------------------------------------|
| GET   | `/api/health`         | Статус сервиса                                  |
| GET   | `/api/subscriptions`  | Результат последнего анализа (или Empty State)  |
| POST  | `/api/upload`         | multipart-загрузка CSV/PDF-выписки → анализ     |
| POST  | `/api/generate-letter`| `{name, amount}` → текст заявления на отмену    |
| POST  | `/api/reset`          | Сбросить состояние (очистить scanner.db)        |
| GET   | `/api/generate-test*` | Тестовые выписки: CSV / PDF / JSON-превью       |

## Как работает анализ

1. **Парсинг CSV** (utf-8/cp1251, разделители `;`/`,`/tab, алиасы колонок)
   или **PDF** (`pdfplumber`): многострочный и однострочный форматы Сбера,
   распознавание знака/суммы/₽, чистка времени и шапок.
2. **Нормализация названий**: `YNDX_PLUS`, `YNDX.MUSIC`, `ЯНДЕКС.ПЛЮС` →
   одна подписка «Яндекс Плюс» (словарь брендов + fallback-группировка по токенам).
3. **Детект периодичности**: медиана интервалов ~20–40 дней (месяц) или
   ~340–390 (год); суммы кластеризуются с допуском ±15%, поэтому переживается
   смена цены (промо 99 ₽ → полные 299 ₽) — актуальная цена берётся с
   последнего ценового уровня; дубли в один день не ломают детект.
4. **Вхождения**: подписки из словаря `INCLUDED_IN` (Кинопоиск → Яндекс Плюс,
   Звук/Okko → СберПрайм, …) получают бейдж «Входит в …».
5. **Deep links**: словарь `CANCEL_LINKS` ведёт на страницу управления/отмены
   сервиса; для неизвестных — поиск «как отменить подписку».
6. **Хранение**: результат анализа — одна строка в SQLite
   (`backend/storage.py`), состояние переживает перезапуск.

```bash
python -m pytest backend/tests -v
```

## Docker (для хостинга)

```bash
docker build -t subscanner .
docker run -p 8000:8000 subscanner
```

Образ подходит для бесплатного хостинга контейнеров (Render, Railway,
Koyeb и т.п.) — тогда у сканера появится постоянная публичная ссылка.

## Режим разработки

```bash
cd backend  && python -m uvicorn main:app --port 8000   # API на :8000
cd frontend && npm run dev                              # UI на :5173 (прокси /api)
```
