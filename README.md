# Сбер.Сканер Подписок

Загрузите банковскую выписку — найдём забытые подписки и посчитаем, сколько вы сможете сэкономить.

**Онлайн-демо:** https://ehity.github.io/sber-subscription-scanner-/

## Что умеет

- Разбирает выписки Сбербанка в **CSV и PDF** (кодировки utf-8/cp1251, все форматы строк)
- Находит регулярные списания и определяет **периодичность** (месячные и годовые подписки)
- Видит **смену цены** (промо → полная) и честно считает экономию за год
- Помечает **«двойные» подписки** внутри экосистемных: Кинопоиск внутри Яндекс Плюса, Звук и Okko внутри СберПрайма
- Отсекает не-подписки: переводы, ЖКХ и бюджетные платежи, розничные покупки и QR
- Даёт **прямые ссылки на отмену** и готовое заявление об отключении автопродления (для российских сервисов — со ссылками на ст. 32 ЗоЗПП и ст. 782 ГК РФ)
- **Работает без сервера**: в браузерной версии весь анализ выполняется прямо на странице, есть тестовые выписки и календарь ближайших списаний

## Как запустить

1. **Онлайн** — открыть демо по ссылке выше. Ничего устанавливать не нужно.
2. **Локально (полная версия с PDF и сохранением результатов):**
   ```
   pip install -r subscription-web/requirements.txt
   subscription-web\start_web.bat   (Windows, двойной щелчок)
   ```
   Сервер поднимется на http://127.0.0.1:8000
3. **Docker:**
   ```
   docker build -t subscanner subscription-web
   docker run -p 8000:8000 subscanner
   ```

## Структура репозитория

```
├─ .github/workflows/pages.yml     автопубликация сайта на GitHub Pages
├─ docs/analysis-rules.md          правила анализа выписки (спека)
└─ subscription-web/
   ├─ README.md                    подробная инструкция по запуску
   ├─ requirements.txt             библиотеки Python для сервера
   ├─ start_web.bat, icon.ico      запуск одной кнопкой на Windows
   ├─ Dockerfile, render.yaml      контейнер и хостинг Render
   ├─ backend/                     СЕРВЕР (Python + FastAPI)
   │  ├─ main.py                   API: приём выписки, ответы, письма
   │  ├─ analyzer.py               «мозг»: поиск подписок в выписке
   │  ├─ storage.py                SQLite: результат переживает рестарт
   │  ├─ services_db.py            справочник сервисов и ссылок отмены
   │  ├─ test_generator.py         генератор тестовых выписок
   │  └─ tests/                    58 проверок (pytest)
   └─ frontend/                    ВНЕШНОСТЬ САЙТА (React + Vite + Tailwind)
      └─ src/
         ├─ App.jsx, components/   экран, карточки подписок, баннеры, график
         ├─ lib/analyzer.js        «мозг» для браузера (порт analyzer.py)
         └─ api.js                 связь с сервером / автономный режим
```

Тесты: `python -m pytest subscription-web/backend/tests -q` — 58 проверок.

Подробное описание анализа и деплоя — в [subscription-web/README.md](subscription-web/README.md).
